# 交互式聊天演示

本目录提供交互式聊天工具，用于以角色扮演场景测试 HER 模型。

## 快速开始

```bash
# 基础聊天（使用 200 个来自经典文学的 CoSER 场景）
python chat_demo.py

# 显示系统思考过程
python chat_demo.py --show-think

# 显示角色内心想法
python chat_demo.py --show-rolethink

# 使用内置简易场景（2 个场景：《傲慢与偏见》《了不起的盖茨比》）
python chat_demo.py --simple
```

## 功能

- **角色扮演**：以经典文学角色身份与 AI 对话
- **多轮对话**：保持对话历史与上下文
- **双层思考展示**：可选择显示系统思考与角色内心
- **格式转换**：将 XML 标签转为可读格式：
  - `<role_thinking>` → `[内心想法]`
  - `<role_action>` → `(肢体动作)`
- **自动保存**：退出时保存对话记录
- **中文交互**：界面、提示词与角色回复均使用中文

## 使用方法

### 交互模式

```bash
python chat_demo.py
```

脚本会依次提示你：
1. 选择场景（作品与情境）
2. 选择 AI 扮演的角色
3. 选择你要扮演的角色
4. 开始聊天！

### 聊天中的命令

| 命令 | 功能 |
|------|------|
| `退出` / `quit` / `exit` / `q` | 结束聊天 |
| `清空` / `clear` | 清空对话历史 |
| `历史` / `history` | 查看当前对话记录 |

## 示例场景

### CoSER 数据集（200 个场景）

默认使用 **CoSER 测试集**（`coser_scenarios.json`），包含 200 个来自经典文学的丰富场景：

- **傲慢与偏见**（伊丽莎白·班纳特、达西先生、班纳特先生等）
- **冰与火之歌**（琼恩·雪诺、提利昂·兰尼斯特、丹妮莉丝·坦格利安等）
- **了不起的盖茨比**（杰伊·盖茨比、尼克·卡拉威、黛西·布坎南等）
- **杀死一只知更鸟**（阿提克斯·芬奇、斯考特·芬奇等）
- **1984**（温斯顿·史密斯、朱莉娅、奥布莱恩等）
- **哈利·波特**（哈利·波特、赫敏·格兰杰、罗恩·韦斯莱等）
- **魔戒**（佛罗多、甘道夫、阿拉贡等）
- 以及另外 150+ 个著名小说场景！

每个场景包含：
- **书名**与作者背景
- **场景描写**与详细环境
- 所有参与者的**人物设定**
- 角色的**初始想法**与动机
- **主题/情境**摘要

> 说明：CoSER 原始场景文本可能为英文，演示会通过中文系统提示词引导模型用中文进行角色扮演。

### 内置场景（2 个简易示例）

若你更想用简单场景，或不想依赖完整数据集，可加 `--simple` 加载 2 个基础中文场景：
- 《傲慢与偏见》（班纳特先生与伊丽莎白）
- 《了不起的盖茨比》（盖茨比与尼克·卡拉威）

## 选项

| 选项 | 说明 | 默认值 |
|------|------|--------|
| `--model-path` | HER 模型目录路径 | `.`（当前目录） |
| `--show-think` | 显示 `<system_thinking>` | False |
| `--show-rolethink` | 显示 `<role_thinking>` | False |
| `--scenario` | 场景编号 | 交互式选择 |
| `--character` | 角色编号 | 交互式选择 |
| `--simple` | 使用 2 个内置场景，而非 200 个 CoSER 场景 | False |

## 输出格式

模型生成的回复包含：

1. **系统思考**（可选显示）：
   - 第三人称分析如何扮演该角色
   - 规划并推理本次回复

2. **角色回复**：
   - **角色内心** `[...]`：角色的内心想法（他人不可见）
   - **角色动作** `(...)`：肢体动作与神态
   - **对白**：自然对话

## 说明

1. **系统思考**：用于训练与分析，不写入对话历史
2. **角色内心**：角色的内心想法，其他角色不可见
3. **角色动作**：他人可见的肢体行为
4. **对白**：角色说出口的话

## 使用建议

- 聊天时保持角色身份
- 在消息中提供足够上下文
- 运用角色的背景知识
- 耐心等待——模型会带推理地生成回复

## 故障排查

**模型加载失败？**
- 确认模型文件位于正确目录
- 检查 GPU 显存是否充足

**回复为空？**
- 尝试调整温度（默认：0.7）
- 检查提示词格式

**角色表现不一致？**
- 查看人物设定
- 确保你的消息与场景上下文相符
